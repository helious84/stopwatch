# Play 스토어 등록정보 초안

## 한국어
**앱 이름 (30자):** 달리는 스탑워치 - 트랙 랩 타이머

**간단한 설명 (80자):** 선수가 트랙을 달리며 시간을 보여주는 스탑워치. 랩마다 선수가 늘어나 기록 비교가 한눈에!

**자세한 설명:**
숫자만 보는 스탑워치는 이제 그만. 노란 선수가 트랙을 한 바퀴 돌면 1분, 위치만 봐도 몇 초인지 알 수 있어요.

■ 랩마다 늘어나는 선수
랩을 누르면 그 랩의 선수가 자기 기록 위치에 멈춰 서서 만세! 출발선에 가까이 선 선수일수록 빠른 랩이에요. 최고 기록은 초록, 최저 기록은 빨강으로 바로 보여요.

■ 기록이 사라지지 않아요
앱을 닫거나 휴대폰이 꺼져도 측정이 계속돼요. 다시 열면 1/100초까지 정확히 이어집니다.

■ 이런 기능도 있어요
· 1/100초 정밀 측정, 무제한 랩
· 트랙 한 바퀴 30초 / 1분 / 2분 / 5분 선택
· 지난 기록 보관, 공유, CSV 내보내기
· 실수로 초기화해도 되돌리기
· 측정 중 화면 꺼짐 방지, 진동·효과음
· 다크 모드, 가로 화면, 한국어/영어
· 광고 없음, 개인정보 수집 없음, 오프라인 동작

달리기 인터벌, 수영 랩, 공부·발표 시간 재기, 요리까지 — 시간을 '보는' 스탑워치를 써보세요.

## English
**Title:** Track Stopwatch - Lap Timer
**Short description:** A stopwatch where runners circle a track. Each lap adds a runner so you can compare at a glance.

## 스크린샷 구성 (폰 세로 1080×1920 권장, 최소 4장)
1. 달리는 중 + 랩 3~4개 (메인 콘셉트) — 문구: "위치만 봐도 시간이 보여요"
2. 랩 8개 이상, 최고/최저 표시 — "출발선에 가까울수록 빠른 랩"
3. 기록 화면 펼친 상태 — "지난 기록 보관·공유·CSV"
4. 다크 모드 — "밤에도 편안하게"
5. 가로 화면 — "가로로 크게"
6. 설정 화면 — "트랙 한 바퀴 시간 선택"
